# Dewey brand

> **The current logo and icons are placeholders.** A friend said they look one-shotted by AI, and they were: generated as code in a few rounds. They stay in use until a hand-drawn version replaces them.

## Logo to-do (Owen)

1. **Sketch 20–30 tiny thumbnails on paper.** Drops, Dewey with glasses, a lowercase "d", the word itself. Bad ones are fine; quantity first.
2. **Pick 2–3 you like for a reason you can explain.** Not "it looks clean", but "the glasses make it feel like a librarian".
3. **Give it one detail only Dewey would have.** Ideas: a drop wearing glasses, a library-card shape, a "d" whose loop is a drop. The drop on its own is the obvious first idea and reads generic.
4. **Write "dewey" by hand 10–20 times** with a marker on white paper (bouncy, neat, quick). Keep one with character, even if it's imperfect. This replaces the stand-in font (Shantell Sans), which reads as "AI/template".
5. **Photograph the sketches and the lettering** (phone camera is fine) and hand them to Claude to trace into clean files: icon sizes, dark and tinted iOS icons, Chrome 16/32/48/128, and the lockups below.
6. **Show friends again,** old next to new, and ask what feels made-by-a-person and what feels generated.

Also on Owen's list: register `dewey.study`, check the name on the App Store and Chrome Web Store, and rename the GitHub repo.

Keep from the current direction unless the sketches say otherwise: the name, the teal palette, the rule that only the logo is hand-drawn (UI text stays clean), and the "for Schoology" descriptor.

## Icons

- `icons/ios/app-icon-1024.png`: App Store / Xcode icon (square, no transparency; iOS rounds the corners). `-dark` and `-tinted` are for iOS 18 icon modes.
- `icons/chrome/icon{16,32,48,128}.png`: extension icons. They have a thin white edge so they read on dark toolbars.

## Rules

- Leave at least half the drop's width of empty space around a lockup.
- Below ~24px tall, use the drop alone.
- Dark pine ink (`#04342C`) on light, mist (`#E1F5EE`) on dark. The drop's fill is always teal (`#1D9E75`).
- Don't straighten the letters, swap the font, or drop the ink outline.
- Only the logo is hand-drawn. Headlines, body text and buttons stay in a clean UI font.
