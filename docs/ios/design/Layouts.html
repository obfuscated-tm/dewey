Dewey layouts

Six options for making the iPhone app feel designed, all in the Dew theme (the new default). Each screen gets one hero, fewer bordered boxes, and its own density: Grades is dense, the Assignment page is airy. The library idea (Dewey Decimal, the librarian) shows up as a shape or a layout, never as a texture or a hand-drawn font; New York serif is only for titles and grade letters.

Pick any mix: e.g. "G1 + C1 + A1 + T1". Options with the same letter replace each other.
