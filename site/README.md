# site/

The legal pages for dewey.owen64.me (Cloudflare Worker `dewey-site`, static assets).
Only these two pages are in the repo so far; the rest of the site is deployed from
outside it. Each file is the whole deployed page, so it replaces the deployed
`privacy.html` / `terms.html` as-is (they're served at `/privacy` and `/terms`).

- `privacy.html`: Privacy
- `terms.html`: Terms of Use

What each one says, and the rule for keeping them true, is in [docs/LEGAL.md](../docs/LEGAL.md).
