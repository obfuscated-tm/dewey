340Law

What Dewey won't do.

  • Change anything on Schoology. It reads. Submitting happens on Schoology's own page, with Schoology's own button.
  • Touch your tests. It never opens or starts a quiz, and goes completely quiet while you have one open.
  • Ask for your password. It uses the Schoology login you already have.
  • Send your stuff anywhere. No analytics, no account, no server of ours. Saved classes are plain files in a folder you pick.
  • Get in the way. One switch in Schoology's corner hides all of it. Alt+Shift+K stops a save mid-run.

The details are in the privacy policy, written in plain English.

004Computers

Get Dewey.

About two minutes, no coding. Dewey isn't in the Chrome Web Store yet, so it installs from a folder.

  1. Download and unzip

    dewey-extension.zip (version {{EXT_VERSION}}). Unzip it and move the dewey-extension folder somewhere it can stay, like Documents. Delete the folder and Chrome removes Dewey.

  2. Load it into Chrome

    Go to chrome://extensions, turn on Developer mode (top right), click Load unpacked and pick the folder. Pin Dewey from the puzzle-piece menu.

  3. Open Schoology

    Dewey's Welcome card takes it from there, including where to save your classes.

Chrome may show a “Disable developer mode extensions” bubble. That's normal for anything installed from a folder; close it.

Updating to a new version

Download the new ZIP, replace the old dewey-extension folder with it (same place, same name), click ↻ on Dewey in chrome://extensions, then refresh Schoology. Your settings and saved classes stay.

030Reference

Questions.

Is it really free?

Yes. No ads, no paid tier, no account.

Can my teacher see that I use it?

Dewey only reads pages you can already see, and changes nothing on Schoology, so there's nothing new for anyone to see. It shows you your own information, laid out better.

Will it work with my school's Schoology?

Dewey is built and tested on one school's Schoology. Other schools use the same pages, so it should work; if something looks off at yours, it's a bug, not you.

Why isn't it in the Chrome Web Store?

Not yet. Until it is, it installs from a folder, which is why Chrome asks for Developer mode. It's the same extension either way.

Is this cheating?

No. It shows your own assignments and grades, and saves class material you already have access to. It never opens a test, and it switches itself off while one is open.
