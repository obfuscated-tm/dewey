Get Dewey

About two minutes, no coding. Dewey isn't in the Chrome Web Store yet, so it installs from a folder.

  1. Download and unzip

    Unzip it and move the dewey-extension folder somewhere it can stay, like Documents.

    Download ({{EXT_VERSION}})

  2. Load it into Chrome

    Go to chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.

  3. Open Schoology

    Dewey's Welcome card takes it from there, including where to save your classes.

Updating to a new version

Replace the old dewey-extension folder with the new one (same place, same name), click ↻ on Dewey in chrome://extensions, then refresh Schoology. Your settings and saved classes stay.
